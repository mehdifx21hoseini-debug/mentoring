# MetaFactory 3.48.0 preview

انتخاب نماد MT5 بر اساس همان حساب، کاهش تخلیهٔ اجباری حافظه و اصلاح نمایش وضعیت زنده.

- پیش از آماده‌کردن اکسپرت MT5، ورود همان حساب از رابط رسمی MetaTrader5 تأیید می‌شود. سپس از فهرست نمادهای همان حساب، نمادی با قیمت مثبت معتبر و کندل M1 قابل خواندن انتخاب می‌شود. نام ثابت یا نماد حساب دیگر، ملاک انتخاب نیست. نماد ترجیحی قبلی نیز باید دوباره این بررسی را بگذراند.
- نماد بدون کندل، غیرفعال، با قیمت نامعتبر یا دادهٔ بیش از هفت روز قدیمی تأیید نمی‌شود. قیمت آخر هفته تا این حد پذیرفته می‌شود؛ بازبودن بازار در همین لحظه شرط نیست. بررسی حداکثر ۳۲ نامزد دارد. اگر هیچ نامزدی تأیید نشود، خطای روشن داده می‌شود و شروع اکسپرت روی نماد حدسی انجام نمی‌شود.
- بررسی روی یک نسخهٔ خصوصی مشترک، با فایل‌های بومی متاتریدرِ همان نسخهٔ مدیریت‌شده انجام می‌شود؛ اکسپرت‌های کاربر و فایل‌های ورود موقت به آن کپی نمی‌شوند. برای هر حساب ورود تازه لازم است. بین حساب‌های همان سرور پردازش کمکی قابل استفادهٔ دوباره است و پس از حدود ۳۰ تا ۴۰ ثانیه بیکاری بسته می‌شود. ورود/پاسخ IPC بودجهٔ ۲۵ ثانیه دارد؛ کپی اولیهٔ فایل‌ها و استخراج runtime جداگانه زمان می‌برد. اگر خود نسخهٔ خصوصی هم نیازمند LiveUpdate باشد، این بودجه ممکن است کافی نباشد و باید دوباره بررسی شود. در زمان بررسی یک متاتریدر خصوصی و Python موقت به بار سیستم افزوده می‌شود؛ ۳۹ پردازش Python دائمی ایجاد نمی‌شود.
- آغاز MT5 همچنان یک نمودار خصوصی با اکسپرت گزارش‌خوان و Algo Trading خاموش دارد. بررسی نماد و گزارش‌خوان سفارش معاملاتی ارسال نمی‌کنند. منطق اکسپرت‌ها، محاسبات مالی، دراودان، تاریخچه و فاصلهٔ انتشار داده‌ها تغییر نکرده‌اند.
- متاتریدرهای دارای پایش زنده از تخلیهٔ اجباری working set در حالت کوچک‌شده مستثنا شده‌اند. این کار می‌تواند بازخوانی مکرر از pagefile و مکث دیسک را کاهش دهد؛ ممکن است عدد RAM مصرفی ظاهری بالاتر بماند. رزرو حافظهٔ خودِ ۳۹ متاتریدر حذف نمی‌شود و روان‌بودن همه روی رم ۸ گیگ تضمین نشده است.
- وقتی گزارش زندهٔ تازه، معتبر و متعلق به همان حساب داریم، خطای قدیمی اتصال یا نبود پنجره بر وضعیت «باز است» غلبه نمی‌کند. دادهٔ کهنه یا متعلق به حساب دیگر این امتیاز را ندارد. وضعیت بستن/به‌روزرسانی واقعی حفظ می‌شود.
- اصلاح ۳.۴۷.۹ نیز همراه است: MT5 هنگام بازیابی LiveUpdate تا ۹۰۰ ثانیه برای برگشت اجرای قبلی فرصت دارد؛ برگشت زودتر بلافاصله پذیرفته می‌شود. این زمان تأخیر اجباری نیست و سرعت updater شرکت MetaQuotes را تغییر نمی‌دهد. MT4 همچنان مهلت قبلی و مسیر آغاز تک‌نموداری تأییدشده را دارد.

برای آزمایش، متافکتوری را ببندید و نصب کنید. ابتدا فقط MT5-41 را ببندید و از نسخهٔ جدید اجرا کنید؛ افزودن دستی نمودار یا اکسپرت لازم نیست. نماد و برچسب زنده را بررسی کنید، سپس تعداد بیشتری را به‌تدریج باز کنید. نصب به‌تنهایی نمودار متاتریدرهای از قبل باز را عوض نمی‌کند. اگر بررسی اولیه تأیید نشد، متن خطای جدید/بررسی سیستم برای تشخیص لازم است؛ کلیک پیاپی روی اجرا نکنید.

اعتبارسنجی ساخت در محیط Linux/Mono با اسمبلی‌های مرجع .NET Framework 4.5 انجام شده است. اجرای واقعی بروکر، SDK بومی MT5 و اندازه‌گیری سرعت یا مصرف حافظه روی ویندوز اینجا ممکن نیست؛ پذیرش نهایی روی سیستم کاربر لازم است. آزمون‌های منطق و رابط مصنوعی، انتخاب نماد جایگزین، مرز هویت حساب، دادهٔ نامعتبر، آخر هفته، حفظ حالت فقط‌خواندنی و سازگاری ورود قبلی را پوشش می‌دهند. نسخه‌ها، منابع داخل برنامه و تطابق برنامهٔ داخل نصب‌کننده بررسی شده‌اند. هیچ گزارش خصوصی یا رمز حساب در بسته قرار ندارد.
