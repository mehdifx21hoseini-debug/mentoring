# MetaFactory 3.69.5 preview

اجرای مدل ۱ از آخرین طرح تأییدشده:

- دکمهٔ Run با زمینهٔ سبز زمردی و آیکون و متن سفید؛ قسمت فلش کمی تیره‌تر.
- بخش انتخاب‌شده‌ها مستطیلیِ روشن با گوشه‌های کم‌گرد، نوشتهٔ تیره و تیک خاکستری؛ شکل کپسولی قبلی حذف شده است.
- اندازه، محل کلیک، انتخاب همه، فلش حالت اجرا و عملکرد دکمه‌ها حفظ شده‌اند. تغییر فقط روی همین دو کنترل اعمال می‌شود.

کد گزارش‌خوان‌های MT4/MT5، اتصال حساب، محاسبات، گزارش‌گیری، باز و بسته‌کردن متاتریدرها، تنظیمات و داده‌های دانشجوها نسبت به 3.69.4 تغییر نکرده‌اند. اکسپرت MT4 همان 1.09 است؛ این نسخه اکسپرت جدید ندارد. برای دیدن ظاهر جدید متافکتوری را دوباره اجرا کنید.

نمای واقعی انگلیسی و فارسی، انتخاب گروهی و تست‌های برنامه بررسی می‌شوند؛ هیچ اطلاعات یا گزارش خصوصی کاربر در بسته قرار ندارد.
