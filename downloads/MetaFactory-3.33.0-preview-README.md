# MetaFactory 3.33.0 — پیش‌نمایش ویندوز

این بسته شامل فایل نصب اصلی، سورس کامل، اسکریپت‌های MT4/MT5، ابزار بررسی MT5 و وابستگی‌های همراه، راهنمای ساخت و قالب Excel است. اطلاعات و رمزهای واقعی دانشجوها در بسته قرار نگرفته‌اند.

## تغییرات

- پایین صفحه کنار نوار آبی، تعداد کل، گزارش تازهٔ موفق، بدون گزارش تازه، ناموفق، باقی‌مانده و در صورت وجود فقط گزارش قبلی/متوقف‌شده نمایش داده می‌شود. «تازه خوانده نشد» هنگام اجرا شامل افراد باقی‌مانده نیز هست؛ با ناموفق نهایی یکی نیست.
- دکمهٔ «توقف گزارش‌گیری» ادامهٔ صف و متاتریدرهای خصوصی همین نوبت را متوقف می‌کند. گزارش‌های کامل‌شده حفظ می‌شوند. دکمهٔ «نتایج» دلیل هر حساب را نشان می‌دهد؛ پس از پایان یا توقف، نتیجه باز می‌شود و می‌توان خروجی Excel گرفت یا خوانده‌نشده‌ها را دوباره بررسی کرد.
- خلاصهٔ هر نوبت به‌طور خودکار در %APPDATA%\MT Manager\report-runs ذخیره می‌شود. خروجی نتیجه رمز ندارد.
- گزارش قبلیِ ذخیره‌شده از موفقیت تازه جداست. خطای گزارش تازه «نیاز به بررسی» نمایش می‌دهد؛ حساب بدون تاریخچه به‌صورت پیش‌فرض فعال شمرده نمی‌شود. فهرست کامل برچسب‌ها در source/STATUS-LABELS-fa-en.md است.
- غیرفعال: Inactive · 14d / غیرفعال · ۱۴ روز؛ قانون قبلی بیش از ۱۴ روز معاملاتی دوشنبه تا جمعه و نداشتن پوزیشن باز حفظ شده است.
- خطاهای موقت اتصال یا شروع‌نشدن اسکریپت پس از سایر حساب‌ها فقط یک بار دیگر امتحان می‌شوند. خطای قطعی رمز تکرار خودکار ندارد. انتخاب نماد چارت از تاریخچهٔ نصب اصلی/AppData هم استفاده می‌کند.
- قبل از اجرای هر متاتریدر، RAM آزاد با حاشیهٔ سیستم‌عامل و مصرف مشاهده‌شدهٔ نسخه‌ها بررسی می‌شود. کمبود حافظه، پرشدن سقف MT4، بسته‌شدن زودهنگام یا بالا نیامدن پنجره، ادامهٔ صف را با پیام روشن متوقف می‌کند؛ نسخه‌های از قبل باز بسته نمی‌شوند. اجرای ۱۰۰ نسخه تضمین نمی‌شود؛ محدودیت‌های ویندوز و متاتریدر همچنان برقرارند.
- نام میانبر دسکتاپ MetaFactory است و میانبرهای قدیمی شناخته‌شدهٔ کاربر مهاجرت می‌کنند؛ مسیر داده و نام داخلی exe برای سازگاری حفظ شده‌اند.
- قابلیت‌های نسخهٔ قبل شامل مرتب‌سازی ستون‌ها، گروه‌بندی Demo/Real، ورود Investor/Master از Excel و پشتیبان، نشان M فقط برای حالت مستر و ثبت سریع همراه بررسی پس‌زمینه حفظ شده‌اند.

## نصب و اعتبارسنجی

از پوشهٔ installer فایل MetaFactory-Setup-3.33.0-preview.exe را اجرا کنید. از داده‌ها پشتیبان داشته باشید. قالب ورود در templates قرار دارد.

ساخت با اسمبلی‌های مرجع رسمی .NET Framework 4.5 انجام شد. ۱۲۴۹ بررسی منطقی، ۴۰ بررسی رابط کاربری در هر زبان فارسی و انگلیسی و ۱۱ آزمون Python موفق شدند. یک آزمون قدیمی چارت به دلیل نبود python3 در تصویر Mono اجرا نمی‌شود. نسخهٔ PE/Assembly، فایل اجرایی جاسازی‌شدهٔ نصاب و ابزارهای همراه بررسی شدند.

این محیط Linux/Mono است؛ اتصال واقعی بروکر، کامپایل MQL با MetaEditor و مهاجرت میانبر Windows COM روی ویندوز آزمایش نشده‌اند. زمان اتصال واقعی با بروکر و سیستم شما تغییر می‌کند؛ این نسخه برای بررسی روی ویندوز منتشر شده است.
