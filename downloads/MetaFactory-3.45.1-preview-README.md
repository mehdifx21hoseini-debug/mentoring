# MetaFactory 3.45.1

در گزارش‌ها فقط عنوان «دراودان کلی» و مقدار درصد نمایش داده می‌شود؛ مانند «دراودان کلی: 58.67%». متن طولانی روش محاسبه از گزارش متن و زیرعنوان کارت حذف شده و در توضیح هنگام نگه‌داشتن موس باقی مانده است.

این تغییر شامل گزارش روز، گزارش متن انتخاب‌شده، کپی/ذخیره و ارسال زمان‌بندی‌شده می‌شود. محاسبه و خواندن تاریخچه همان نسخهٔ 3.45.0 است.

برنامه را ببندید و فایل نصب پوشهٔ installer را اجرا کنید. پوشهٔ source حاوی سورس کامل و تست‌هاست.

کار روی بازکردن تعداد زیاد متاتریدر، مرحلهٔ بعدی است؛ تنظیمات آن در این نسخه تغییر نکرده است.

بررسی: ۱۹۴۴ تست موفق، صفر شکست؛ یک تست قدیمی وابسته به Python اجرا نشد. نسخه و محتوای فایل نصب نیز تأیید شد.
