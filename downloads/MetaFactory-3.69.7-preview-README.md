# MetaFactory 3.69.7 preview

مبنا: نسخهٔ تأییدشدهٔ 3.69.5؛ ظاهر Run سبز و بخش انتخاب مستطیلیِ روشن حفظ شده است. رنگ قرمز Close از نسخهٔ ردشده وارد نشده است.

تغییر مسیر Run به درخواست کاربر:

- فاصلهٔ اضافهٔ خودکار ۷، ۱۰ یا ۱۵ ثانیه‌ای MT5 هنگام کمبود یا نامشخص‌بودن رم حذف شد.
- مکث خودکار ۵ ثانیه‌ای پس از خطای تخصیص منابع از مسیر اجرا حذف شد؛ ثبت خطا و ادامهٔ بقیهٔ صف حفظ شده است.
- هیچ سقف کلِ تعداد یا شرط ردکردنِ اجرای دستی بر اساس رم اعمال نمی‌شود. کمبود رم فقط مشاهده و ثبت می‌شود.
- فقط فاصلهٔ اجرای انتخابی کاربر و آماده‌سازی جداگانهٔ هر نسخه باقی می‌ماند. برای کمترین فاصله، Settings > Start interval را روی 0 بگذارید؛ رابط فارسی: تنظیمات > فاصلهٔ اجرا، مقدار ۰.
- توقف/لغو توسط کاربر، بسته‌شدن خود برنامه، جلوگیری از اجرای تکراری همان نسخه و تشخیص تعلق فرایندها حفظ شده‌اند. برنامه برای جا بازکردن، متاتریدر قبلی را نمی‌بندد.
- گروه‌بندی MT4 در Sandboxie حفظ شده است: با پرشدن گروه، گروه بعدی استفاده می‌شود. این گروه‌بندی سقف کل تعداد نیست و حذفش می‌تواند بازکردن MT4های بیشتر را مختل کند.

این تغییر، محدودیت منابع گرافیکی ویندوز یا خطای داخلی متاتریدر را حذف نمی‌کند و تضمین اجرای تعداد نامحدود پنجرهٔ واقعی نیست. ساخت فرایند، ساخت پنجره و اتصال زنده سه مرحلهٔ جدا هستند؛ خطاهای واقعی همچنان ثبت می‌شوند.

دامنهٔ تغییر فقط صف اجرای دستی است. بررسی ورود حساب‌ها، هم‌زمانی گزارش‌های موقت، گزارش‌خوان‌ها و صحت محاسبات مالی، کد MT4/MT5، مدیریت آپدیت، بستن نسخه‌ها، قالب و داده‌ها تغییر نکرده‌اند. اکسپرت MT4 همان 1.09 است. این نسخه نیازی به تعویض اکسپرت فعال ندارد.

اعتبارسنجی شامل صف واقعی برنامه با راه‌انداز شبیه‌سازی‌شده، حافظهٔ آزاد بسیار کم/نامشخص، تعداد بالای نسخه و خطاهای تخصیص منابع عمدی است؛ این آزمون اجرای واقعی صدها متاتریدر روی ویندوز نیست. فایل نصب و منابع داخلی بررسی می‌شوند. هیچ دادهٔ ورود یا لاگ خصوصی کاربر در بسته نیست.
