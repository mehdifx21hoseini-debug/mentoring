# MetaFactory 3.47.3 preview — MT4 live chart and automatic DLL

کاربر تأیید کرد که روشن‌کردن DLL در MT4، گزارش زنده را به‌روز می‌کند. این نسخه تنظیمات شروع MT4 را برای همان نیاز اصلاح می‌کند.

- هنگام «اجرا» روی MT4 بسته با گزارش‌خوان زنده، ExpertsDllImport=true در فایل شروع قرار می‌گیرد. این مجوز در سطح همان ترمینال MT4 است، نه یک مجوز جداگانه فقط برای گزارش‌خوان. اجازهٔ معامله/AutoTrading تغییر نمی‌کند.
- حالت سبک/پروفایل خالی در این مسیر دیگر چارت گزارش‌خوان را حذف نمی‌کند.
- اگر پروفایل انتخاب‌شده نمودار ندارد، یک پروفایل MetaFactoryLive با نمودار سادهٔ نماد انتخاب‌شده آماده می‌شود. فایل انتخاب پروفایل قبلی پشتیبان‌گیری می‌شود. چارت‌ها، default.tpl و اکسپرت‌های موجود بازنویسی نمی‌شوند. اتصال اکسپرت از تنظیمات شروع قبلی انجام می‌شود.
- مسیر MT5، اسکریپت‌های بومی و محاسبات مالی تغییر نکرده‌اند. اصلاح نگهداری فایل شروع تا ۱۸۰ ثانیه از نسخهٔ ۳.۴۷.۲ حفظ شده است.

اعمال تنظیمات نیازمند بستن MT4 مورد آزمایش و بازکردن آن از متافکتوری جدید است؛ ترمینال‌های ازقبل‌باز تغییر نمی‌کنند. ابتدا یک MT4 را آزمایش کنید. پس از کامل‌شدن شروع باید بدون تغییر دستی DLL، گزارش به‌روز شود. اگر نشد، خروجی «بررسی سیستم» را ارسال کنید.

این نسخه رفع علت کندی چنددقیقه‌ای راه‌اندازی را ادعا نمی‌کند. محیط ساخت امکان اجرای واقعی Windows/MetaEditor/بروکر ندارد؛ رفتار مقصد باید بررسی شود. ساخت با مراجع .NET Framework 4.5 و تطابق برنامهٔ داخل نصب‌کننده بررسی می‌شود. بسته شامل سورس کامل و فایل نصب، بدون گزارش و اطلاعات خصوصی کاربر است.

نتیجهٔ اعتبارسنجی: ۲۱۸۱ آزمون موفق، صفر خطا؛ یک بررسی قدیمی Python اجرا نشد. ۱۴ آزمون مصنوعی رابط کاربری موفق؛ نسخهٔ فایل‌ها، منابع و تطابق نصب‌کننده تأیید شد. اجرای واقعی متاتریدر روی ویندوز در محیط ساخت موجود نیست.
