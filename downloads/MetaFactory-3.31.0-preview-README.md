# MetaFactory 3.31.0 — نسخهٔ آزمایشی ثبت سریع Excel

این نسخه برای اعتبارسنجی روی Windows ارائه شده است. فایل نصبی 3.30.4 نیز در پوشهٔ downloads باقی مانده است.

## رفتار جدید

- ثبت همهٔ دانشجوهای معتبر از Excel بدون انتظار برای ورود به بروکر و بدون ساخت یک متاتریدر برای هر دانشجو.
- نمایش فوری دانشجوها در صفحهٔ اصلی؛ ساخت نسخهٔ شخصی هنگام اولین بازکردن.
- بررسی اتصال در پس‌زمینه، با یک یا دو پردازش خصوصی بسته به منابع سیستم.
- مشاهدهٔ وضعیت و دلیل هر حساب: **ابزارها ← بررسی اتصال دانشجوها**.
- توقف، ادامه، تلاش دوباره و خروجی Excel نتیجه بدون رمز. صف پس از بازکردن دوبارهٔ برنامه بازیابی می‌شود.
- MT5: تأیید ورود تازه با رابط رسمی MetaQuotes؛ بدون انتظار برای بسته‌شدن و نوشته‌شدن ژورنال.
- MT4: ابزار کوچک فقط‌خواندنی با MetaEditor؛ اگر ساخت آن ممکن نباشد، بررسی محدود ژورنال استفاده می‌شود.

## آزمون

- 1095 تست منطقی: پاس؛ صفر خطا. یک تست قدیمی chart retry به دلیل نبود python3 داخل تصویر Mono اجرا نشد.
- 11 بررسی رابط کاربری انگلیسی و 11 بررسی فارسی: پاس.
- 9 تست Python برای پاسخ موفق، رمز ردشده، قطع ارتباط، عدم تطابق حساب/سرور و عدم افشای رمز: پاس.
- نسخهٔ اسمبلی/PE، تطابق payload نصب‌کننده با برنامهٔ تست‌شده و منابع ابزارهای اتصال: تأیید شد.
- زمان ثبت 100 دانشجوی مصنوعی در تست رابط Linux: حدود 0.3 تا 0.7 ثانیه؛ این زمان، زمان اتصال به بروکر نیست.
- **اتصال واقعی به بروکر، کامپایل MQL4 با MetaEditor و اجرای IPC بومی MT5 روی Windows در این محیط آزموده نشده است.**

## استفاده

متاتریدر بروکر باید نصب باشد. برای MT5، Windows 64-bit سازگار با Python 3.12 لازم است؛ Python همراه برنامه است و نصب دستی لازم ندارد. قبل از نصب آزمایشی از بخش پشتیبان‌گیری برنامه یک پشتیبان بگیرید. ابتدا چند ردیف را وارد و وضعیت را در صف بررسی کنید.

حساب ثبت‌شده با حساب تأییدشده فرق دارد. «تأیید شد» نتیجهٔ ورود تازه در زمان بررسی است، نه تضمین ارتباط همیشگی. اتصال به بروکر همچنان اینترنت و پاسخ سرور لازم دارد. اجرای پس‌زمینه به معنی اجرای بدون پردازش متاتریدر نیست و پنجره ممکن است لحظه‌ای در شروع دیده شود.

فایل Source.zip شامل سورس، اسکریپت‌ها، وابستگی همراه MT5، مجوزها و تست‌ها است. داده و رمز واقعی دانشجوها در بستهٔ جدید قرار ندارد.
