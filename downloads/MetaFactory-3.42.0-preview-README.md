# MetaFactory 3.42.0 preview

اجرای خودکار MT4های اضافی از طریق Sandboxie نصب‌شده، روی همان ویندوز و دسکتاپ.

- ۲۸ جای اجرای عادی برای MT4؛ موارد اضافی در گروه‌های اختصاصی ۲۴تایی، بدون سقف کل در صف برنامه.
- چهار جای اجرای عادی برای گزارش‌خوان‌ها رزرو می‌شود؛ بستن یا جابه‌جایی خودکار حساب‌های موجود انجام نمی‌شود.
- مسیر رمز/ژورنال مشترک با پوشهٔ اصلی همان کپی؛ تشخیص و بستن PID واقعی، نه راه‌انداز Sandboxie.
- MT5 و الگوریتم‌های گزارش‌گیری تغییر نکرده‌اند.

ZIP شامل فایل نصب در installer، سورس کامل و تست‌ها در source و راهنمای فارسی source/SANDBOXIE-fa.md است. فاقد رمزها و داده‌های دانشجویان و فاقد نصاب Sandboxie است. ساخت از source/build.sh با Mono و Microsoft .NET4.5 reference assemblies انجام می‌شود.

**این نسخه آزمایشی است:** اجرای دستی یک مورد اضافه روی دستگاه کاربر موفق بوده، اما مسیر خودکار گروهی هنوز روی ویندوز تأیید نشده است. ابتدا چند مورد و گزارش یک حساب را امتحان کنید، سپس تعداد را بالا ببرید. DefaultBox و رجیستری ویندوز را تغییر ندهید. MetaFactory را بیرون از Sandboxie اجرا کنید.
