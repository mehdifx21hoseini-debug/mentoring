# MetaFactory 3.46.1 — اجرای خودکار گزارش‌خوان زنده (آزمایشی)

متاتریدرهای بسته را در متافکتوری انتخاب کنید و «اجرا» را بزنید. برای MT4 و MT5، گزارش‌خوان مستقل و تنظیمات همان حساب در پس‌زمینه آماده و به تنظیمات شروع متاتریدر اضافه می‌شود. اتصال دستی اکسپرت به چارت برای این مسیر لازم نیست. اولین ساخت به MetaEditor نصب‌شده در ویندوز نیاز دارد؛ ساخت‌های بعد از کش استفاده می‌کنند.

پس از بازشدن، «ابزارها ← پایش زندهٔ حساب‌های باز» را باز کنید. دریافت در این پنجره خودکار روشن است؛ فقط دریافت پیام تازهٔ همان حساب، فعال‌شدن واقعی را تأیید می‌کند. برنامه حساب آماده‌شده را به فهرست زنده اضافه می‌کند. برای متاتریدر از قبل بازشده، آن را خودتان ببندید و با «اجرا» دوباره باز کنید.

برای جدا ماندن از چارت دارای اکسپرت، بازهٔ زمانی استفاده‌نشده انتخاب می‌شود. اگر قالب چارت موجود یا بازهٔ جدا قابل تشخیص نباشد، آماده‌سازی خطا می‌دهد. فایل‌ها و اکسپرت‌های قبلی بازنویسی نمی‌شوند. مجوزهای عمومی معامله و DLL متاتریدر تغییر نمی‌کنند. برای MT4، دریافت تاریخچهٔ کامل معتبر با گزارش‌خوان فعلی همچنان نیازمند اجازهٔ DLL است؛ اگر مجوز موجود فعال نباشد، اطلاعات جاری دریافت می‌شود ولی تاریخچه تأییدنشده می‌ماند. این نسخه خودکار آن مجوز عمومی را تغییر نمی‌دهد.

گزارش‌گیری دستی مستقل باقی است. بستن پنجرهٔ پایش فقط دریافت در متافکتوری را متوقف می‌کند؛ اکسپرت تا بسته‌شدن متاتریدر یا جداشدن از چارت می‌تواند ادامه دهد. برنامه، اکسپرت معامله‌گر نیست و فرمان معاملاتی ندارد.

این بسته شامل installer و سورس کامل است. ابتدا برنامه را ببندید، فایل نصب را اجرا کنید و با یک MT4 و یک MT5 آزمایش کنید.

اعتبارسنجی: ساخت .NET Framework4.5، آزمون منطق و تنظیمات شروع و رابط کاربری. محیط ساخت ویندوز و MetaEditor ندارد؛ پذیرش واقعی تنظیمات Expert/ExpertParameters و رفتار چارت هنگام شروع باید روی متاتریدر سیستم مقصد تأیید شود. بنابراین این نسخه آزمایشی است؛ فعال‌شدن همهٔ حساب‌ها روی ویندوز هنوز ادعا نمی‌شود. گزارش خطای ساخت/شروع و وضعیت تازهٔ پایش برای تشخیص مشکل قابل استفاده است.

۲۰۹۸ آزمون منطق موفق، صفر شکست؛ یک آزمون قدیمی وابسته به Python اجرا نشد. رابط زنده: ۲۰ بررسی فارسی/انگلیسی موفق.
