# MetaFactory 3.31.1 — نسخهٔ آزمایشی صف Excel و بررسی سریع‌تر

## استفاده

ZIP را Extract کنید و فایل `installer/MetaFactory-Setup-3.31.1-preview.exe` را اجرا کنید. پیش از نصب از اطلاعات برنامه پشتیبان بگیرید. ابتدا با چند حساب واقعی صحت ورود و نام سرور را بررسی کنید. سورس کامل در پوشهٔ `source` است.

در صفحهٔ افزودن از Excel، «افزودن و بررسی اتصال» را بزنید. اطلاعات یکجا ثبت می‌شود و همان صفحه باز می‌ماند تا وضعیت و دلیل هر حساب را ببینید. توقف، تلاش دوباره و ذخیرهٔ نتیجه در همان صفحه هستند. اگر خودتان پنجره را ببندید، بررسی در پس‌زمینه ادامه دارد و از «ابزارها ← بررسی اتصال دانشجوها» قابل مشاهده است.

## کاهش تأخیر

- **MT5:** برای حساب‌های متوالی روی یک سرور، متاتریدر خصوصی و رابط Python دوباره بسته و باز نمی‌شوند. برای هر حساب، درخواست ورود تازه با شماره حساب، سرور و توکن مستقل همچنان الزامی است. نتیجهٔ قبلی به حساب بعدی منتقل نمی‌شود.
- **MT4:** تأیید مستقیم اتصال فوراً ثبت و نمایش داده می‌شود؛ پایان بستن پردازش شرط نمایش موفقیت نیست. قبل از شروع دوبارهٔ همان نسخه، پایان پردازش کنترل می‌شود. MT4 برای حساب بعدی همچنان یک نشست ورود جدید لازم دارد.
- **هم‌زمانی:** با حداقل دو پردازندهٔ منطقی، ۶ گیگابایت حافظه و ۲٫۵ گیگابایت حافظهٔ آزاد در شروع برنامه، دو حساب بررسی می‌شوند؛ در غیر این صورت یک حساب. تنظیمات گزارش‌گیری معاملات تغییر نکرده است.
- **حساب کند:** پس از بررسی کوتاه به نوبت تکمیلی می‌رود تا بقیه ادامه داشته باشند.
- پردازش آمادهٔ MT5 پس از پنج ثانیه بیکارماندن آزاد می‌شود. تغییر سرور، توقف، پاسخ نامعتبر و timeout باعث کنار گذاشتن نشست قابل استفادهٔ مجدد می‌شوند.

## اعتبارسنجی

- 1103 تست منطقی: پاس؛ صفر خطا. یک تست قدیمی chart retry به دلیل نبود python3 در تصویر Mono اجرا نشد.
- 18 بررسی UI در هر یک از زبان‌های فارسی و انگلیسی: پاس؛ شامل باقی‌ماندن صفحهٔ Excel، نمایش نتیجه، توقف، تلاش مجدد بدون تکرار دانشجو و نتیجهٔ نهایی فایل خروجی.
- 11 تست Python/MT5: پاس؛ شامل سه درخواست متوالی با حساب‌های متفاوت، ردشدن رمز در درخواست وسط و الزام ورود مستقل برای هر حساب.
- نسخهٔ اسمبلی/PE، تطابق فایل داخل نصب‌کننده با برنامهٔ تست‌شده و تطابق ابزار همراه با سورس: تأیید شد.

**آزمون اتصال واقعی بروکر، اجرای بومی IPC روی Windows و کامپایل MQL4 با MetaEditor در محیط ساخت Linux انجام نشده‌اند. این تست‌ها زمان واقعی اتصال را اندازه نمی‌گیرند؛ نمی‌توان از آن‌ها عدد یا درصد مشخصی برای افزایش سرعت روی بروکر نتیجه گرفت.**

نصب متاتریدر بروکر لازم است. Python همراه برنامه است؛ برای MT5 ویندوز ۶۴ بیتی سازگار با Python 3.12 لازم است. ابزار مستقیم MT4 به MetaEditor بروکر نیاز دارد؛ اگر آماده نشود، بررسی محدود ژورنال استفاده می‌شود. اجرا در پس‌زمینه همچنان یک پردازش واقعی متاتریدر است و ممکن است پنجره هنگام شروع لحظه‌ای دیده شود.

فایل نتیجه رمز ندارد. داده و رمز واقعی دانشجوها در این بسته قرار داده نشده است. مجوزها و هش وابستگی‌های Python/MetaTrader5/NumPy در `source/bridge/runtime-win64.zip` موجودند. نسخه‌های پیشین در GitHub حفظ شده‌اند.
