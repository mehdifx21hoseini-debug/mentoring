# MetaFactory 3.69.6 preview

تغییر ظاهری تأییدشده:

- دکمهٔ Close در حالت انتخاب دانشجوها قرمز آجری با متن و آیکون سفید است؛ بخش فلش کمی تیره‌تر.
- دکمهٔ Close open در حالت عادی نیز همان ظاهر قرمز را دارد.
- حالت غیرفعال با قرمزِ خاموش‌تر نمایش داده می‌شود. نبود متاتریدر باز، دکمهٔ غیرفعال را فعال نمی‌کند.
- Run سبز و بخش انتخاب مستطیلیِ روشنِ نسخهٔ 3.69.5 حفظ شده‌اند.

فقط رنگ و رسم همین دو دکمه تغییر کرده است. کلیک اصلی، فلش، منوهای بستن، تعدادها، محدودهٔ انتخاب، اندازه‌ها، تأییدها و رفتار بستن متاتریدرها عین نسخهٔ قبل هستند. کد گزارش‌گیری، اتصال، لایو، MT4/MT5 و داده‌های دانشجوها تغییر نکرده است. اکسپرت MT4 همان 1.09 است؛ این نسخه به تعویض اکسپرت نیاز ندارد.

برای دیدن ظاهر جدید متافکتوری را پس از نصب دوباره اجرا کنید. نمای انگلیسی و فارسی، انتخاب گروهی و تست‌های برنامه بررسی می‌شوند. هیچ گزارش یا اطلاعات حساب خصوصی در بسته قرار ندارد.
