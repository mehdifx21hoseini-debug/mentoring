# MetaFactory 3.50.6 preview

MT5 startup fixes, based on the confirmed EURUSD synchronization timeout and delayed updater restarts:

* Before attaching the live expert, use a recent verified same-account symbol hint, or verify a readable symbol with that account using the existing bounded 8-second private probe. Cold startup can take longer; failed verification stops with a message instead of attaching to an unverified fixed EURUSD chart. The current own chart is preferred when supported by the account's recent feed and own catalogue.
* Retain the original MT5 startup configuration during the MetaFactory session for delayed updater restarts. It contains the stored login and password, restricted on Windows to the current user and SYSTEM; failure to apply protection stops launch. Application shutdown removes it. This addresses a confirmed missing-config path; it does not prove every login prompt has the same cause, and cannot fix wrong credentials or broker authentication failures.
* A built-in watcher applies per-user RunAsInvoker compatibility to trusted MetaQuotes executables for registered MT5 copies and their exact own-cache updater paths named in terminal journals. Windows Authenticode trust and MetaQuotes identity must both pass. Untrusted/unknown paths remain unchanged. This grants no administrator rights and does not click secure-desktop consent. Explicit vendor elevation may still prompt; the first newly discovered updater can prompt before the watcher observes it. Permanent removal of all UAC prompts is NOT guaranteed. No separate elevated service/task, no global UAC change. Prior per-file compatibility values are backed up under HKCU\Software\MetaFactory\ScopedUpdaterCompatibility. Turning off the existing current-privilege terminal launch option restores our unchanged values on the next MT5 Run; unrelated later user edits are preserved.

Original appearance, financial validation, MT4, queue and native collectors remain unchanged. The MT5 expert source is still1.05. No need to restart healthy MT4/MT5 just to update MetaFactory, but changed startup behavior applies on subsequent MT5 launches. Close MetaFactory, install, reopen it, then test only one previously affected MT5 from Live Run. Do not launch38copies on8GB.

Actual Windows ACL, trust/compatibility behavior, private broker symbol verification and login/update behavior require Windows confirmation. See source/VERIFICATION-3.50.6.json for checks. Financial tests are not evidence that UAC automation works on the user's computer.
