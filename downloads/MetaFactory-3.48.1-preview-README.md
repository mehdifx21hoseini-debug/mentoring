# MetaFactory 3.48.1 preview — authenticated MT5 symbol-probe startup

این نسخه اصلاح مسیر کمکیِ انتخاب نماد است. در ۳.۴۸.۰ نسخهٔ خصوصی ابتدا با تنظیمات بدون ورود حساب اجرا می‌شد؛ سپس Python به آن متصل می‌شد و ورود را انجام می‌داد. روی نسخهٔ خصوصی تازه، این ترتیب می‌تواند پنجرهٔ Open an Account ایجاد کند و ارتباط IPC را متوقف کند. عکس کاربر با این حالت سازگار است؛ بدون مسیر پردازش/ژورنال، هویت همان پنجره قطعاً تأیید نشده است.

تغییر:
- فقط در بررسی نماد MT5، اجرای ناشناسِ جداگانه حذف شد. رابط رسمی MetaTrader5 از اولین initialize، شمارهٔ حساب، رمز و سرورِ درخواست را دریافت می‌کند. این اطلاعات از stdin به ابزار کمکی می‌رسند؛ به خط فرمان یا فایل تنظیمات ورود افزوده نمی‌شوند.
- تأیید ورود صریح و تطابق شمارهٔ حساب/سرور/توکن همچنان لازم است. سپس قیمت و کندل همان حساب برای انتخاب نماد بررسی می‌شود. شکست initialize، ورود ردشده یا دادهٔ حساب دیگر نمی‌تواند نماد تأییدشده ایجاد کند.
- پردازش ایجادشده توسط SDK تنها از مسیر دقیقِ نسخهٔ خصوصی از قبل رزروشده شناسایی و به مالکیت worker اضافه می‌شود. برنامه آن را پنهان می‌کند و هنگام خطا، لغو یا پایان بیکاری می‌بندد. پردازش متاتریدر دانشجو یا نصب اصلی برای این منظور انتخاب نمی‌شود. این مسیر به شناسایی پردازش با دسترسی ویندوز وابسته است.
- runtime کش‌شده نسخهٔ جداگانه دارد تا ابزار Python نسخهٔ قبلی دوباره استفاده نشود.
- مسیر بررسی ورود معمولی، MT4، اکسپرت‌های گزارش‌خوان، محاسبات گزارش، انتخاب نماد همان حساب، حالت یک نمودارِ اصلی و تنظیمات Algo Trading آن تغییر نکرده‌اند. کاهش تخلیهٔ اجباری حافظه و انتظار LiveUpdate از نسخهٔ قبلی حفظ شده‌اند.

روش آزمایش:
۱. پنجرهٔ Open an Account را Cancel کنید و فقط همان پنجرهٔ اضافهٔ بدون حساب را ببندید؛ حساب جدید نسازید و رمزهای حساب‌های اصلی را عوض نکنید.
۲. متافکتوری را ببندید و ۳.۴۸.۱ را نصب کنید.
۳. فعلاً فقط MT5-41 را از متافکتوری اجرا کنید. حساب و نماد باید خودکار آماده شوند؛ نمودار یا اکسپرت دستی اضافه نکنید.
۴. اگر پنجره ماند یا گزارش نرسید، متن خطای جدید و «بررسی سیستم» تازه لازم است تا مشخص شود کدام مسیر اجرا یا ورود متوقف شده است. کلیک تکراری روی اجرا نکنید.

ساخت و آزمون در Linux/Mono با اسمبلی‌های مرجع .NET Framework 4.5 انجام می‌شود. اجرای واقعی SDK بومی، پنجرهٔ بروکر و ورود ویندوز در این محیط ممکن نیست؛ این نسخه اصلاح مبتنی بر کد و آزمون مصنوعی است و نیاز به تأیید کاربر روی همان حساب دارد. سرعت یا مصرف حافظهٔ واقعی روی سیستم کاربر اندازه‌گیری نشده است. هیچ رمز یا گزارش خصوصی در بسته قرار ندارد.
