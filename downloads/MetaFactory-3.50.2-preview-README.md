# MetaFactory 3.50.2 preview

Based on3.50.1 with original3.48.2 appearance and unchanged native EAs/reporting math. This release fixes the overconservative90-second startup gate identified in the user's30-copy report.

- A prior terminal's missing window, busy CPU, pending history or updater no longer occupies an initializer slot. The original StartPace configured-maximum/early-ready behavior remains; a memory minimum gap is added only when needed:7s below1536MB,10s below768MB,15s below384MB,7s when memory cannot be measured. Healthy memory keeps original early-ready timing. No total terminal cap, forced close or claim of infinite RAM capacity.
- Native updater replacement processes are rebound to their original A/B observation only for the exact executable path and unchanged account/cohort, after the previous process exits. Initial launch time remains the anchor. PID chains and restart counts are recorded, CPU segments accumulate without double counting, and previous-process/other-account heartbeats cannot mark the replacement ready. Legacy observations remain explicitly untracked rather than being retroactively invented.
- Normal/live launch options remain. Native snapshot fallback transport, dynamic display-symbol repair, financial calculations and strict freshness/history identity validation are unchanged. No EA source change, so an existing source/compiler cache can be reused.
- Systemcheck gathers bounded read-only metadata for downloaded MT5 updaters, including full cached paths, descriptions, versions, embedded certificate subjects and per-path compatibility flags. This is diagnostic evidence, not signature trust validation. This version does not auto-accept UAC, install an elevated helper/task, disable UAC or change compatibility flags.

Close MetaFactory and terminals before installing. For initial validation use20same accounts (10MT4+10MT5) in live mode, wait2minutes after the final launch and send full Systemcheck text. The prior30-copy run reached325/512MB free RAM: shorter launch waits cannot remove actual memory pressure. A downloaded vendor updater or broker connection can still take time; speed has not been benchmarked on actual Windows in this workspace.

Validation:2315logic checks passed0failed, one pre-existing Python chart retry skipped in the Mono image. New PID-chain tests use actual helper child processes; synthetic queue tests exercise production PaceTick with earlier headless processes and bounded low-memory spacing. Microsoft.NET4.5 references, installer resources/version/payload verified. No actual Windows/broker performance or UAC-dialog validation available here. All native scripts/bridge, main UI appearance and financial math are byte identical to3.50.1.
