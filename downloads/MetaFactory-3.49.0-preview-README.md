# MetaFactory 3.49.0 preview — ظاهر جدید

این نسخه اجرای طرح ظاهری تأییدشده است و بر پایهٔ ۳.۴۸.۲ ساخته شده است.

تغییرات ظاهری:
- هدر زغالی با جست‌وجوی روشن و دسترسی ثابت به پشتیبانی، ابزارها و تنظیمات. فرمان‌های موجود حفظ شده‌اند و برای ارسال و زمان‌بندی، میان‌بر مستقیم همان منوهای قبلی اضافه شده است.
- نوار عملیات روشن، دکمهٔ اصلی آبی، فاصله‌ها و رنگ‌های یکدست. در عرض کم، فرمان‌ها به ردیف بعد می‌روند تا از صفحه بیرون نمانند. فرمان‌های مربوط به انتخاب حساب‌ها همان عملکرد قبلی را دارند.
- تنظیمات با پنج دستهٔ واقعیِ گزینه‌های موجود: عمومی و مسیرها، اجرای متاتریدر، گزارش‌گیری، سبک‌سازی و ویندوز. محتوای هر دسته اسکرول می‌شود و دکمه‌های ذخیره و انصراف ثابت‌اند. گزینه یا مقدار پیش‌فرض جدیدی اضافه نشده است.
- کارت‌های مستقل تلگرام، بله و ایمیل همراه با آیکون و کلید روشن/خاموش. انتخاب کارت فقط جزئیات آن کانال را نمایش می‌دهد و روشن‌بودن کانال‌ها را عوض نمی‌کند؛ انتخاب هم‌زمان هر سه مقصد حفظ شده است. وضعیت نمایش‌داده‌شده «فعال برای ارسال» است، نه ادعای آزمایش اتصال.
- فیلدهای رمز همچنان پوشیده، و ایمیل، شناسهٔ گفتگو، توکن و مسیرها چپ‌به‌راست‌اند. دکمهٔ ذخیره همان اعتبارسنجی و نگهداری رمزهای قبلی را دارد؛ انصراف تغییرات را دور می‌ریزد. منطق ارسال زمان‌بندی‌شده تغییری نکرده است.
- آیکون‌های کانال‌ها با رسم برداری سبک و محلی نمایش داده می‌شوند و دانلود اینترنتی یا کتابخانهٔ سنگین جدیدی لازم نیست. نشان بله یک بازطراحی سادهٔ بصری است، نه فایل رسمی برند.

حفظ رفتار:
تمام ۴۲ فایل دیگرِ C#، تمام گزارش‌خوان‌های MQL4/MQL5 و فایل‌های رابط MT5 با نسخهٔ ۳.۴۸.۲ یکسان‌اند. فایل‌های Core و Program فقط تغییر شمارهٔ نسخه دارند. بدنهٔ ذخیره و انتخاب پوشهٔ تنظیمات، اعتبارسنجی و ذخیرهٔ مقصدها، نگهداری رمز، فرمان اجرای حساب‌ها، به‌روزرسانی گزارش‌ها و منوی ابزارهای قبلی بررسی و یکسان‌بودن آن‌ها تأیید شده است. محاسبات، دراودان، کنترل تازگی، اجرای متاتریدرها، محدودیت‌ها، سیاست حافظه و زمان‌بندی تغییر نکرده‌اند. این نسخه شامل بهینه‌سازی تازه‌ای برای ظرفیت اجرای ۳۹ متاتریدر نیست.

نصب:
متافکتوری را ببندید و نصب‌کننده را اجرا کنید. تنظیمات و حساب‌های موجود باید از مسیر قبلی خوانده شوند؛ نیازی به ورود دوبارهٔ حساب‌ها یا تغییر تنظیمات ارسال نیست. تغییرات صفحهٔ تنظیمات فقط با دکمهٔ ذخیره اعمال می‌شوند.

اعتبارسنجی:
ساخت با اسمبلی‌های مرجع .NET Framework 4.5 انجام شده است. ۲۲۴۴ آزمون منطق موفق و بدون خطا بودند؛ یک بررسی قدیمی Python در تصویر Mono اجرا نشد. فرم تنظیمات، انتخاب هم‌زمان کانال‌ها، ذخیره/انصراف، حفظ رمزها، ماسک رمز و ورودی‌های LTR، نوار اصلی در عرض کمتر و یکپارچگی نمایش گزارش زنده در آزمون‌های رابط بررسی شدند. نسخه‌های اسمبلی و منابع و تطابق برنامهٔ داخل نصب‌کننده نیز بررسی می‌شوند.

آزمون‌های تصویری در محیط Linux/Mono با داده‌های ساختگی انجام شده‌اند؛ این محیط جای آزمون نهایی ویندوز و نمایش متن فارسی روی سیستم کاربر را نمی‌گیرد. هیچ حساب، رمز یا گزارش خصوصی کاربر در بسته قرار ندارد.
