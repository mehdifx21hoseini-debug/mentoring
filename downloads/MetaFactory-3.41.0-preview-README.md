# MetaFactory 3.41.0 preview

اصلاح و بررسی ظرفیت اجرای متاتریدر روی همان ویندوز اصلی.

- اجرای دستی MT4 و MT5 بدون سقف تعداد در برنامه؛ حافظه کم فقط هشدار می‌دهد.
- حذف توصیهٔ قدیمی ۴۰/۶۴ مگابایت Desktop Heap و ارائهٔ اصلاح به ۲۰۴۸۰ کیلوبایت با پشتیبان‌گیری و تأیید مدیر ویندوز.
- آزادسازی منابع بررسی پردازش‌ها و ثبت کد خروج واقعی، زمان اجرا و وضعیت حافظه برای متاتریدرهایی که خودکار بسته می‌شوند.
- موتور گزارش‌گیری و اسکریپت‌های MT4/MT5 تغییر نکرده‌اند.

داخل ZIP: پوشه installer شامل فایل نصب و پوشه source شامل سورس کامل، تست‌ها، اسکریپت‌های MQL و راهنمای SAME-WINDOWS-CAPACITY-fa.md. حساب‌ها و رمزهای دانشجویان همراه بسته نیستند. برای ساخت، فایل source/build.sh و راهنمای refasm-dl را ببینید؛ متاتریدر و MetaEditor بروکر باید جدا نصب باشند.

**مهم:** این نسخه هنوز عبور واقعی از مرز ۳۲ را روی ویندوز تأیید نکرده است. اگر مقدار Heap فعلی 65536/40960 است، راهنمای داخل بسته را برای اصلاح و Restart همان ویندوز دنبال کنید. اگر مورد سی‌وسوم باز هم بسته شد، خروجی «ابزارها ← بررسی سیستم» نسخهٔ جدید را ارسال کنید.
