# MetaFactory 3.50.8 preview: run managed MT5 without automatic updates

Implements the user's requested alternative to automatically accepting UAC: pause the per-copy automatic update staging path before launch. It does not click Yes or elevate anything.

A new Settings checkbox "Run MT5 without automatic updates" defaults ON. For numbered MT5 copies started by MetaFactory, the current-user MetaQuotes cache key is derived from the uppercase full installation directory (UTF16LE MD5), matching six actual cache paths from the user's reports. Before a closed copy starts, an existing liveupdate directory is renamed to liveupdate.MetaFactory-backup and preserved; an owned marker file occupies the original liveupdate path and is held against write/delete access while MetaFactory runs. No terminal executable, account, EA, chart, history, UAC policy, firewall or ACL is changed. MD5 is a cache identifier, not a signature check. Unknown files, links or backup collisions are not overwritten; errors explain how to turn the option off and return to prior launch behavior.

Reversible: turn the checkbox OFF, save, then close/reopen the affected copy from MetaFactory. Held barriers are restored when disabling; owned persisted barriers are restored before the next launch of each copy. Preserved cache bytes return to their original folder. Marker/cache backup can outlive MetaFactory; do not delete cache folders manually. This is a current-user per-copy policy, not a global Windows update disable. Original installed broker terminal is outside numbered-copy scope.

Cancel any already pending old UAC dialog before testing; the tool refuses to invalidate an existing consent request. Already-running terminals are not retroactively changed.
