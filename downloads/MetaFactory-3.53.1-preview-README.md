# MetaFactory 3.53.1 preview

- تنظیمات در دو بخش ثابت «عمومی و اجرا» و «ارسال گزارش» جمع شده‌اند. گزینه‌های کم‌استفاده در بخش بازشوندهٔ همان صفحه قرار دارند؛ تنظیمات قبلی حفظ می‌شوند.
- آیکون یادداشت برای همهٔ دانشجوها کنار نام دیده می‌شود: خاکستری برای یادداشت خالی و آبی برای یادداشت ذخیره‌شده. روی آیکون کلیک کنید؛ گزینهٔ تکراری از سه‌نقطه حذف شده است.
- پس از پذیرش عملیات دستیِ اجرا، گزارش و بستن، تمام تیک‌ها برداشته می‌شوند. انتقال، افزودن یا حذف از پوشه، ذخیرهٔ یادداشت، ویرایش حساب و کپی مشخصات و خروجی اکسل هم انتخاب‌ها را پس از انجام برمی‌دارند. عملیات لغوشده/ردشده و گزارش خودکار انتخاب‌ها را پاک نمی‌کنند؛ هدف‌های عملیات قبل از پاک‌شدن انتخاب‌ها حفظ می‌شوند.
- پنجره و ورودی بررسی اتصال دانشجوها حذف شده‌اند. بررسی داخلیِ ورود گروهی حساب‌ها حفظ شده است.
- تنظیم حافظهٔ پنجره‌های ویندوز و پاکسازی مستقیم در ابزارها هستند. مقدار حافظه قابل انتخاب است (3072، 6144، 12288 یا 20480 KB)؛ بدون زدن اعمال هیچ تغییری صورت نمی‌گیرد. اعمال همچنان اجازهٔ مدیر و راه‌اندازی مجدد ویندوز می‌خواهد.
- منطق و فایل‌های گزارش‌گیری MT4/MT5، تاریخچه، محاسبات، پایش زنده، زمان‌بندی و سیاست به‌روزرسانی تغییر نکرده‌اند.

نصب: متافکتوری را ببندید، نصب‌کننده را اجرا و برنامه را دوباره باز کنید. داده‌ها و یادداشت‌ها حفظ می‌شوند.

Validation uses synthetic accounts under Linux Mono/Xvfb at normal and simulated 125% scale, strict Microsoft .NET Framework 4.5 references, notes persistence/backup tests, queue snapshot/selection checks, two-tab settings persistence and validation checks, and the existing logic suite. No real terminals or delivery transports are launched. Native Windows fonts/DPI and broker execution remain untested. The manual verification-queue window is removed; internal import/account validation remains required for reliable imports.
