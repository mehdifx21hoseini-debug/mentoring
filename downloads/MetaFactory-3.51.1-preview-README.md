# MetaFactory 3.51.1 preview — Graphite & Pearl

Applies approved theme 1 across application-owned windows: graphite headings and native Windows captions, near-white surfaces, shared blue actions, restrained borders, consistent footers and controls. Settings uses a compact fixed frame with a navigation sidebar (right in Persian, left in English); General, Running, Delivery and Advanced remain in one window. Folder selection now adapts to the available settings width.

Common dialog styling covers students, account credentials, copy creation, folders, report selection, Excel export, backup/restore, cleanup, desktop heap and confirmation messages. Custom report text/day text, diagnostics/help, Excel import, connection queue, live monitor and standalone scheduling headings match the same design. The approved main layout is retained and shares the palette.

MT4/MT5 native collectors, reports, financial calculations, freshness proofs, launch queue/pacing, Sandboxie, update policy and sending/scheduling backend are byte-identical to 3.51.0. No new account operations or automatic trading behavior.

Installation: close MetaFactory, install this version, reopen. Existing terminal windows can remain open. Existing installer preserves settings and accounts. Previous 3.51.0 remains available for rollback.

Validation details are recorded with the release. UI checks use synthetic data on Linux Mono/Xvfb; native Windows font rendering, title-bar APIs, DPI and broker execution require user-side verification. OS-owned file/folder dialogs retain their Windows appearance. No change to UAC or automatic update consent handling.
